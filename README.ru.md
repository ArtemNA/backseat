## Что это

Backseat — приложение для Windows, чтобы смотреть, как играют друг друга. Оно похоже на
маленький сервер Discord: комнаты слева, люди в открытой комнате, а их стримы посередине.
Любой в комнате может выйти в эфир, и любой может смотреть, даже несколько стримов сразу.

Видео идёт **напрямую** с компьютера стримера к каждому зрителю. Никто посередине его не
хранит и не перекодирует, поэтому задержка мала (десятки миллисекунд при хорошей связи), а
картинка настолько чёткая, насколько позволяет твой интернет на отдачу.

## Возможности

- **Комнаты по приглашению.** Создай комнату и отправь ссылку или код. Войдут только те,
  у кого есть приглашение. Твои комнаты остаются в списке слева.
- **Чётко и плавно.** 720p, 1080p или 1440p, 30 или 60 кадров, от 2 до 50 Мбит/с,
  кодирование на видеокарте (NVIDIA, AMD или Intel) в AV1, H.265 или H.264.
- **Каждый зритель выбирает сам.** Зритель может попросить качество ниже, чем ты
  стримишь (для медленного интернета), но не выше. Медленный интернет одного зрителя не
  тормозит остальных.
- **Экран или одно окно**, со всем звуком, только со звуком этой программы или без звука.
- **Смена стрима на лету:** другое окно, разрешение, кадры или битрейт, и никому не нужно
  переподключаться.
- **Удобно смотреть:** видео в окне приложения или в отдельном окне, полный экран,
  громкость и выключение звука прямо на видео, статистика на F3.
- **Не мешает:** закрытое окно оставляет Backseat в трее. Обновляется сам.
- **Прямое соединение (бета):** двое могут соединиться вообще без сервера (смотри ниже).
- **На английском, украинском и русском.**

## Как начать

1. Скачай `backseat-setup-X.Y.Z.exe` из [релизов](../../releases/latest) и запусти.
   Он устанавливается только для твоего пользователя Windows, права администратора не
   нужны. Windows SmartScreen может предупредить, что установщик не подписан: выбери
   *Подробнее → Выполнить в любом случае*.
2. Запусти Backseat и выбери, как соединиться:
   - **комната на сервере сигналинга** (обычный способ, любое число людей), или
   - **Напрямую (бета)** — для двух человек без всякого сервера.

### Комнаты

Комнате нужен **сервер сигналинга**: маленькая служба, которая сообщает людям в комнате
друг о друге. Видео через него не идёт. Ты можешь [запустить свой](#сервер-сигналинга) за
несколько минут бесплатно или пользоваться сервером друга.

1. Укажи адрес сервера (вроде `wss://your-server.example.com/ws`) в
   *Настройки → Общие* или в форме входа.
2. *Создай комнату*, дай ей название и нажми кнопку приглашения рядом с названием
   комнаты, чтобы скопировать приглашение. Отправь его друзьям: ссылка открывает Backseat
   сразу в этой комнате.
3. Нажми **Стрим**, выбери экран или окно и выходи в эфир. Друзья нажимают **Смотреть**.

Если связь с сервером на миг оборвётся, Backseat переподключится сам, и стримы
продолжатся.

### Прямое соединение (бета)

Для двух человек, совсем без сервера. Вы один раз обмениваетесь двумя текстами через любой
мессенджер:

![Прямое соединение](docs/images/direct.png)

1. Ты: *Напрямую (бета)* → **Я приглашаю** → *Создать приглашение* и отправляешь текст
   другу.
2. Друг: *Напрямую (бета)* → **Мне прислали приглашение**, вставляет его, нажимает
   *Создать ответ* и отправляет этот текст тебе.
3. Ты вставляешь ответ и нажимаешь *Соединить*. Готово: любой из вас может выйти в эфир,
   а другой — смотреть, можно и одновременно.

Что стоит знать:

- **Только двое.** Для большой компании нужна комната.
- **Без переподключения.** Если соединение оборвётся (сбой Wi-Fi, сон компьютера, смена
  сети), оно завершится, и придётся снова обменяться текстами.
- **Одноразово.** Приглашение срабатывает один раз и только пока приложение, которое его
  создало, открыто.
- **В текстах есть твои сетевые адреса.** Отправляй их только тому, с кем хочешь
  соединиться.
- **В некоторых сетях не работает**, чаще всего в мобильном интернете и за общими адресами
  некоторых провайдеров (CGNAT). То же касается и комнат, потому что видео всегда идёт
  напрямую между двумя компьютерами.
- **Ничего не сохраняется:** прямое соединение не появляется в списке комнат.

## Требования

- Windows 10 или 11, 64-бит.
- Чтобы **стримить**: видеокарта с аппаратным кодированием видео (большинство карт
  NVIDIA, AMD и Intel за последние несколько лет).
- Чтобы **смотреть**: любой не слишком старый ПК. Если видеокарта не умеет декодировать
  AV1, это делает процессор.
- Microsoft Edge WebView2, который есть в Windows 11. Если его нет, установщик доставит.

## Советы

- **Настройки по умолчанию:** *Настройки → Стрим* задаёт, что выбирается перед каждым
  эфиром; *Настройки → Просмотр* — наибольшее качество, которое ты хочешь получать
  (удобно при медленном интернете: стрим на 50 Мбит/с сразу приходит в пределах твоего
  лимита).
- **Клавиши на видео:** двойной клик или F11 — полный экран, Esc — выйти из него, F3 —
  статистика, колёсико мыши — громкость.
- **Лимит отдачи:** в окне выхода в эфир укажи скорость своего интернета на отдачу, и
  Backseat предупредит, когда ещё один зритель не поместится.
- **Логи** для отчётов об ошибках лежат в `%LOCALAPPDATA%\Backseat\logs`.

## Сервер сигналинга

Сервер маленький (`crates/server` в этом репозитории) и не требует особого железа: он
передаёт несколько коротких сообщений на соединение и никакого видео. Один сервер
обслуживает любое число комнат.

### На Render (бесплатно, свой компьютер не нужен)

1. Войди на [render.com](https://render.com) и выбери *New → Web Service*.
2. Подключи этот репозиторий (или свою его копию).
3. Настройки:
   - *Runtime*: Rust
   - *Build command*: `cargo build --release -p server`
   - *Start command*: `./target/release/server`
   - *Health check path*: `/live`
4. После первого развёртывания добавь переменную окружения `STREAMER_KEEP_ALIVE_URL` с
   адресом твоего сервиса и `/live` в конце (например,
   `https://my-backseat.onrender.com/live`): бесплатные сервисы засыпают без дела, а это
   не даёт ему уснуть.
5. В Backseat адрес сервера будет `wss://my-backseat.onrender.com/ws`.

### На своём компьютере или сервере

С установленным [Rust](https://rustup.rs):

```sh
cargo run --release -p server -- 0.0.0.0:7800
```

Тогда адрес — `ws://ТВОЙ-IP:7800/ws`. Чтобы до него достучаться из интернета, открой этот
порт на роутере или поставь сервер за обратным прокси с HTTPS и используй `wss://`.
Хостинги, задающие переменную `PORT`, тоже поддерживаются (сервер тогда слушает
`0.0.0.0:$PORT`).

Что умеет сервер: `/ws` для приложения, `/live` для проверки состояния и `/j/КОД` для
ссылок-приглашений, которые открывают приложение.

## Сборка из кода

Нужны Rust (stable, MSVC), Visual Studio 2022 или её Build Tools с набором для C++,
GStreamer 1.28.8 (официальный установщик MSVC x86_64 с
<https://gstreamer.freedesktop.org/download/>, runtime и файлы для разработки) и NSIS 3.

```powershell
$env:GSTREAMER_1_0_ROOT_MSVC_X86_64 = 'C:\path\to\gstreamer\1.0\msvc_x86_64\'
.\tools\bundle.ps1                     # dist\backseat: приложение с нужными DLL
.\tools\installer.ps1 -WebView2 .\MicrosoftEdgeWebview2Setup.exe
                                       # dist\backseat-setup-X.Y.Z.exe
```

`bundle.ps1` копирует библиотеки и плагины GStreamer, которые использует приложение,
среду Visual C++ и тексты лицензий, и останавливается, если какой-то импорт DLL не найден.
Загрузчик WebView2: <https://go.microsoft.com/fwlink/p/?LinkId=2124703>. Сборку можно
сделать со встроенным сервером, без поля сервера в приложении: передай
`-Server wss://HOST/ws` в `tools\installer.ps1`.

Релизы собирает workflow `release` в `.github/workflows`, когда в репозиторий приходит тег
`vX.Y.Z`; заметки берутся из `CHANGELOG.md`.
