## Що це

Backseat — застосунок для Windows, щоб дивитися, як грають одне одного. Він схожий на
маленький сервер Discord: кімнати зліва, люди у відкритій кімнаті, а їхні стріми
посередині. Будь-хто в кімнаті може вийти в ефір, і будь-хто може дивитися, навіть кілька
стрімів одночасно.

Відео йде **напряму** з комп'ютера стрімера до кожного глядача. Ніхто посередині його не
зберігає й не перекодовує, тому затримка мала (десятки мілісекунд на хорошому зв'язку), а
картинка така чітка, як дозволяє твій інтернет на вивантаження.

## Можливості

- **Кімнати за запрошенням.** Створи кімнату й надішли посилання чи код. Увійдуть лише ті,
  хто має запрошення. Твої кімнати лишаються в списку зліва.
- **Чітко й плавно.** 720p, 1080p чи 1440p, 30 або 60 кадрів, від 2 до 50 Мбіт/с,
  кодування на відеокарті (NVIDIA, AMD чи Intel) в AV1, H.265 або H.264.
- **Кожен глядач обирає сам.** Глядач може попросити меншу якість, ніж ти стрімиш (для
  повільного інтернету), але не більшу. Повільний інтернет одного глядача не гальмує
  інших.
- **Екран або одне вікно**, з усім звуком, лише зі звуком цієї програми або без звуку.
- **Зміна стріму на льоту:** інше вікно, роздільність, кадри чи бітрейт, і нікому не
  треба перепідключатися.
- **Зручно дивитися:** відео у вікні застосунку або в окремому вікні, повний екран,
  гучність і вимкнення звуку просто на відео, статистика на F3.
- **Не заважає:** закрите вікно лишає Backseat у треї. Оновлюється сам.
- **Пряме з'єднання (бета):** двоє можуть з'єднатися взагалі без сервера (дивись нижче).
- **Англійською, українською й російською.**

## Як почати

1. Завантаж `backseat-setup-X.Y.Z.exe` з [релізів](../../releases/latest) і запусти.
   Він встановлюється лише для твого користувача Windows, права адміністратора не
   потрібні. Windows SmartScreen може попередити, що інсталятор не підписаний: обери
   *Докладніше → Усе одно запустити*.
2. Запусти Backseat і обери, як з'єднатися:
   - **кімната на сервері сигналінгу** (звичайний спосіб, будь-яка кількість людей), або
   - **Напряму (бета)** — для двох людей без жодного сервера.

### Кімнати

Кімнаті потрібен **сервер сигналінгу**: маленька служба, що повідомляє людям у кімнаті
одне про одного. Відео через нього не йде. Ти можеш [запустити свій](#сервер-сигналінгу)
за кілька хвилин безкоштовно або користуватися сервером друга.

1. Вкажи адресу сервера (на кшталт `wss://your-server.example.com/ws`) у
   *Налаштування → Загальні* або у формі входу.
2. *Створи кімнату*, дай їй назву й натисни кнопку запрошення біля назви кімнати, щоб
   скопіювати запрошення. Надішли його друзям: посилання відкриває Backseat одразу в цій
   кімнаті.
3. Натисни **Стрім**, обери екран чи вікно й виходь в ефір. Друзі натискають
   **Дивитись**.

Якщо зв'язок із сервером на мить обірветься, Backseat перепідключиться сам, і стріми
триватимуть.

### Пряме з'єднання (бета)

Для двох людей, зовсім без сервера. Ви один раз обмінюєтесь двома текстами через будь-який
месенджер:

![Пряме з'єднання](docs/images/direct.png)

1. Ти: *Напряму (бета)* → **Я запрошую** → *Створити запрошення* і надсилаєш текст
   другові.
2. Друг: *Напряму (бета)* → **Мені надіслали запрошення**, вставляє його, натискає
   *Створити відповідь* і надсилає цей текст тобі.
3. Ти вставляєш відповідь і натискаєш *З'єднати*. Готово: будь-хто з вас може вийти в
   ефір, а інший — дивитися, можна й одночасно.

Що варто знати:

- **Лише двоє.** Для більшої компанії потрібна кімната.
- **Без перепідключення.** Якщо з'єднання обірветься (збій Wi-Fi, сон комп'ютера, зміна
  мережі), воно завершиться, і доведеться знову обмінятися текстами.
- **Одноразово.** Запрошення спрацьовує один раз і лише поки застосунок, що його створив,
  відкритий.
- **У текстах є твої мережеві адреси.** Надсилай їх лише тому, з ким хочеш з'єднатися.
- **У деяких мережах не працює**, найчастіше в мобільному інтернеті й за спільними
  адресами деяких провайдерів (CGNAT). Те саме стосується й кімнат, бо відео завжди йде
  напряму між двома комп'ютерами.
- **Нічого не зберігається:** пряме з'єднання не з'являється в списку кімнат.

## Вимоги

- Windows 10 або 11, 64-біт.
- Щоб **стрімити**: відеокарта з апаратним кодуванням відео (більшість карт NVIDIA, AMD
  та Intel за останні кілька років).
- Щоб **дивитися**: будь-який не надто старий ПК. Якщо відеокарта не вміє декодувати AV1,
  це робить процесор.
- Microsoft Edge WebView2, який є у Windows 11. Якщо його немає, інсталятор доставить.

## Поради

- **Налаштування за замовчуванням:** *Налаштування → Стрім* задає, що обирається перед
  кожним ефіром; *Налаштування → Перегляд* — найбільша якість, яку ти хочеш отримувати
  (зручно на повільному інтернеті: стрім на 50 Мбіт/с одразу приходить у межах твого
  ліміту).
- **Клавіші на відео:** подвійний клік або F11 — повний екран, Esc — вийти з нього, F3 —
  статистика, коліщатко миші — гучність.
- **Ліміт вивантаження:** у вікні виходу в ефір вкажи швидкість свого інтернету на
  вивантаження, і Backseat попередить, коли ще один глядач не вміститься.
- **Логи** для звітів про помилки лежать у `%LOCALAPPDATA%\Backseat\logs`.

## Сервер сигналінгу

Сервер маленький (`crates/server` у цьому репозиторії) і не потребує особливого заліза:
він передає кілька коротких повідомлень на з'єднання й жодного відео. Один сервер
обслуговує будь-яку кількість кімнат.

### На Render (безкоштовно, свій комп'ютер не потрібен)

1. Увійди на [render.com](https://render.com) і обери *New → Web Service*.
2. Під'єднай цей репозиторій (або свою його копію).
3. Налаштування:
   - *Runtime*: Rust
   - *Build command*: `cargo build --release -p server`
   - *Start command*: `./target/release/server`
   - *Health check path*: `/live`
4. Після першого розгортання додай змінну середовища `STREAMER_KEEP_ALIVE_URL` з адресою
   твого сервісу й `/live` у кінці (наприклад, `https://my-backseat.onrender.com/live`):
   безкоштовні сервіси засинають без діла, а це не дає йому заснути.
5. У Backseat адреса сервера буде `wss://my-backseat.onrender.com/ws`.

### На своєму комп'ютері чи сервері

Зі встановленим [Rust](https://rustup.rs):

```sh
cargo run --release -p server -- 0.0.0.0:7800
```

Тоді адреса — `ws://ТВІЙ-IP:7800/ws`. Щоб до нього достукатися з інтернету, відкрий цей
порт на роутері або постав сервер за зворотним проксі з HTTPS і використовуй `wss://`.
Хостинги, що задають змінну `PORT`, теж підтримуються (сервер тоді слухає
`0.0.0.0:$PORT`).

Що вміє сервер: `/ws` для застосунку, `/live` для перевірки стану й `/j/КОД` для
посилань-запрошень, що відкривають застосунок.

## Збірка з коду

Потрібні Rust (stable, MSVC), Visual Studio 2022 або її Build Tools з набором для C++,
GStreamer 1.28.8 (офіційний інсталятор MSVC x86_64 з
<https://gstreamer.freedesktop.org/download/>, runtime і файли для розробки) та NSIS 3.

```powershell
$env:GSTREAMER_1_0_ROOT_MSVC_X86_64 = 'C:\path\to\gstreamer\1.0\msvc_x86_64\'
.\tools\bundle.ps1                     # dist\backseat: застосунок із потрібними DLL
.\tools\installer.ps1 -WebView2 .\MicrosoftEdgeWebview2Setup.exe
                                       # dist\backseat-setup-X.Y.Z.exe
```

`bundle.ps1` копіює бібліотеки й плагіни GStreamer, які використовує застосунок,
середовище Visual C++ і тексти ліцензій, і зупиняється, якщо якийсь імпорт DLL не
знайдено. Завантажувач WebView2: <https://go.microsoft.com/fwlink/p/?LinkId=2124703>.
Збірку можна зробити з вбудованим сервером, без поля сервера в застосунку: передай
`-Server wss://HOST/ws` до `tools\installer.ps1`.

Релізи збирає workflow `release` у `.github/workflows`, коли в репозиторій надходить тег
`vX.Y.Z`; нотатки беруться з `CHANGELOG.md`.
